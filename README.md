### 🚀 Featured Projects

#### ⚡ [ClickPipe — Real-Time Click Analytics Pipeline](https://github.com/ARYAN10227/clickstream-pipeline)
`Redpanda (Kafka)` `Python` `ClickHouse` `Prometheus` `Grafana` `Docker`

Streams every URL-shortener click through Redpanda into ClickHouse with idempotent writes, a dead-letter queue and live Grafana dashboards.
- ⚡ **20,000 events/s** for 5 minutes on a single 4-vCPU machine, **p99 397 ms** end-to-end
- 🔁 **1M-event replay with 50K duplicates** → every event stored exactly once
- 💥 **`kill -9` mid-stream → zero data loss**; 100% of bad records routed to a DLQ

[🎬 Demo video](https://youtu.be/em_TnU8WQkU) · [📊 Results](https://github.com/ARYAN10227/clickstream-pipeline/blob/main/docs/results/final-v1.md) · [☁️ Run it in Codespaces](https://codespaces.new/ARYAN10227/clickstream-pipeline?quickstart=1)
